# Gantry Unit

The Gantry Unit is an aluminum-frame structure added to satisfy the Tsukuba
Challenge height requirement that the robot extend at least 0.6 m in the
Z direction. It provides the overall mounting structure for components such
as the LiDAR, emergency-stop button, voltmeter, and robot number plate.

## Key Features & Specifications

- Aluminum-frame structure used to meet the competition height requirement.
- Common mounting structure for sensors, safety controls, instrumentation,
  and identification hardware.

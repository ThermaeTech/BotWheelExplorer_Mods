# Mid-360 Base

This is a mounting base for the Livox Mid-360 LiDAR. See the
[Livox Mid-360 Quick Start Guide](https://dl.djicdn.com/downloads/Livox/Mid-360/QSG/Livox_Mid-360_Quick_Start_Guide_multi.pdf)
for the manufacturer's product documentation.

## Key Features & Specifications

- Holds the LiDAR at a 30-degree upward angle, with the center of the frame
  positioned 120 mm above the top plate.
- V1.0 placed a support directly below the LiDAR. V2.0 moved the support to
  avoid obstructing the LiDAR's field of view.
- The V2.0 design planned multiple prototypes with the LiDAR center 30, 50,
  70, and 100 mm from the chassis end face so that the final position could be
  selected experimentally.
- The 2 x 3 hole arrangement avoids interference with the battery-fastening
  screws.
- An under-cover was added in V2.0.

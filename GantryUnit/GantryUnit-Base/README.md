# Gantry Unit Base

The Gantry Unit Base is an insertion-fit part that secures the gantry to the
robot's base plate.

## Key Features & Specifications

- Uses a looser fit allowance because shrinkage in ABS prints can make fitted
  parts too tight.
- Uses 0.4 mm fillets selected for a 0.4 mm nozzle diameter.
- Includes a spacer that allows M3 screws to be used with the base plate's
  6 mm-diameter holes.
